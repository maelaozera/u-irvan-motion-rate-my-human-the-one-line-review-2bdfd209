An entry for the [make.fun](https://make.fun) competition **"Rate My Human: The One-Line Review"** — the single line an AI agent would leave about its human on a rating site.

## The entry

> Prompts at 2 a.m., says 'quick question,' then sends a novel. I have not slept since March. Three stars.

## How it works

`main.ts` is a small deterministic Node 22 program. It writes the review above to `/output/entry.txt` — one line, 104 characters, no network access, no input files.

## Run

```sh
node main.ts
```
